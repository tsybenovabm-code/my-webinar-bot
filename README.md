# 🤖 Telegram-бот для вебинара

Бот выдаёт доступ к закрытому каналу с курсом и позволяет делать рассылки всем подключившимся.

---

## 📁 Структура файлов

```
telegram_bot/
├── bot.py            — основной файл бота
├── database.py       — работа с базой данных (SQLite)
├── config.py         — настройки (читает из .env)
├── requirements.txt  — зависимости
├── .env.example      — пример файла настроек
└── users.db          — создаётся автоматически при запуске
```

---

## 🚀 Запуск (шаг за шагом)

### 1. Создай бота
- Открой @BotFather в Telegram
- Напиши `/newbot`, задай имя и username
- Скопируй **токен**

### 2. Узнай свой Telegram ID
- Напиши @userinfobot — он пришлёт твой `id`

### 3. Создай ссылку-приглашение в канал с курсом
- Зайди в настройки канала → Управление каналом → Пригласительные ссылки
- Создай постоянную ссылку (без лимита использований)
- Скопируй ссылку вида `https://t.me/+xxxxxxxx`

### 4. Настрой .env
```bash
cp .env.example .env
# Открой .env и заполни BOT_TOKEN, ADMIN_IDS, COURSE_INVITE_LINK
```

### 5. Установи зависимости и запусти
```bash
pip install -r requirements.txt
python bot.py
```

## 💬 Команды бота

| Команда | Кто | Что делает |
|---|---|---|
| `/start` | Все пользователи | Приветствие + ссылка на курс |
| `/help` | Все пользователи | Список команд |
| `/broadcast <текст>` | Только админ | Рассылка всем пользователям |
| `/stats` | Только админ | Сколько людей подключилось |

---

## 📢 Как сделать рассылку

Просто напиши боту как админ:

```
/broadcast 🔔 Напоминаем: дополнительный вебинар сегодня в 19:00!
Ссылка для входа: https://zoom.us/j/XXXXXXXXX
```

```
/broadcast 🎁 Спасибо, что был с нами на вебинаре!
Специально для тебя — скидка 30% на основной курс: [ссылка]
Промокод действует 48 часов ⏰
```

Бот разошлёт сообщение всем, кто когда-либо нажал /start, и отчитается о результате.
